# 마케팅 홍보 페이지

한국농업기술진흥원(KOAT) 기술이전 마케팅용 정적 웹페이지 모음입니다.

- 페이지 소스는 `docs/`에 있습니다. 빌드 도구 없이 HTML 파일만으로 동작합니다.
- `main` 브랜치의 `docs/`가 바뀌면 GitHub Pages에 자동 배포됩니다(`.github/workflows/pages.yml`).
- 페이지 목록과 수정 방법은 [`docs/README.md`](docs/README.md)를 참고하세요.

현재 작업 중인 페이지는 특허 홍보 페이지(`docs/patents.html`)입니다.
