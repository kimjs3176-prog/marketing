# 강원센터 제2차 집담회 참석기업 × 국유특허 기술이전 매칭

- `20261023_강원센터_제2차_집담회_참석기업_국유특허매칭.xlsx` : 원본 리스트의 마지막 열(P) `매칭 국유특허(기술이전 추천)`에 기업별 추천 특허 2~4건과 적합도(상/중/하)를 추가했습니다.
- `제안서/` : 아이템이 있는 12개 기업별 기술이전 제안서(.docx). 본문은 제안 배경·추천 특허·활용 방안·추진 방안·유의사항이고, 특허별 **기술요약서는 붙임**으로 뒤에 붙어 있습니다. 원본에 기업명이 비어 있어 기업코드로 표기했습니다.
- `_build/` : 다시 생성할 때 쓰는 스크립트입니다. `matches.json`(매칭 데이터)을 고친 뒤 아래 명령을 실행합니다.

```bash
python3 _build/update_excel.py <원본.xlsx> 20261023_강원센터_제2차_집담회_참석기업_국유특허매칭.xlsx
node _build/make_proposals.cjs
```
