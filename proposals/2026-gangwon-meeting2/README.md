# 강원센터 제2차 집담회 참석기업 × 국유특허 기술이전 매칭

- `20261023_강원센터_제2차_집담회_참석기업_국유특허매칭.xlsx` : 원본 리스트의 마지막 열(P) `매칭 국유특허(기술이전 추천)`에 기업별 추천 특허 3건과 AIS 종합점수를 넣었습니다.
- `제안서/` : 아이템이 있는 12개 기업별 기술이전 제안서(.hwpx, 한글). 첨부 양식(`_build/template.hwpx`)을 그대로 따릅니다.
  - 본문: 제안 개요 · 추천 특허 개요 · 도입 체크리스트 · 기대 효과
  - 붙임: 특허별 요약서(서지정보, AI 사업화 평가, 발명 요약·농산업 활용·상용화 전망)
  - 원본에 기업명이 비어 있어 기업코드로 표기했습니다.

## 데이터 출처와 기준

| 항목 | 출처 |
|---|---|
| 특허 검색·서지정보(출원·등록번호, 권리자, 발명자, IPC, 상태) | KIPRIS Plus API (2026. 10. 26. 조회) |
| AI 사업화 평가(종합·기술성·시장성·사업성 점수, TRL), 요약문 | AIS(Agri IP Summary, atipsum.lovable.app) |
| 제안 내용(핵심 기술 → 적용, 인허가, 기대 효과) | 기업 아이템과 특허 내용을 바탕으로 작성 |

- 매칭 기준: 권리자 **대한민국(농촌진흥청장) 단독**, **최근 10년 내 출원(2016. 10. 26. 이후)**, 상태 **등록 또는 공개**.
- 직접 일치하는 국유특허가 없는 아이템(2023-01-003 반려동물 마이크로니들, 2023-01-008 균사체 조미김, 2023-02-014 해양 원료 사료)은 인접 특허로 매칭했고, 해당 제안서의 '추가 개발' 항목에 그 사실을 적었습니다.

## 다시 만들기 (`_build/`)

```bash
cd _build
KIPRIS_API_KEY=... python3 kipris_search.py queries.json out.json  # (선택) 후보 검색
# selection.json(기업별 출원번호 3건)과 proposals.json(제안 문구)을 수정한 뒤
KIPRIS_API_KEY=... python3 kipris_verify.py                         # 서지정보 → kipris.json
python3 ais_fetch.py                                                # AIS 분석 → ais.json (새 특허만 조회)
python3 update_excel.py <원본.xlsx> ../20261023_강원센터_제2차_집담회_참석기업_국유특허매칭.xlsx
python3 make_hwpx.py                                                # 제안서 → ../제안서/
```

KIPRIS API 키는 저장소에 넣지 않고 환경변수로 전달합니다.
